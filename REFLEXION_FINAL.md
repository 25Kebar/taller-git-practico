#¿Qué fue lo más difícil de la actividad? ¿Qué te costó más entender?
-Unas de las cosas mas dificiles que tuve fue usar el comando git add -p por que aunque necesitaba editarlo, aparecia con ciertas inteverciones que no me favorecian del todo, otro cosa que me dificulto fue fusionar las ramas por que me podrian aparecer cualquier problema

#¿Cuál de todos los comandos crees que usarás con más frecuencia y por qué?
- git commit -amend por que me aparece util, git blame por que puedo ver la informacion de todo, git branch para poder ver todas las ramas, git checkout -b y git checkout aunque tambien con swicht para poder crear y cambiarse de rama, git log -n 1 para ver el hash de mi commit
#¿En qué situaciones usarías el comando que deshace el último commit eliminando
cambios frente al que crea un commit inverso?
-Usaria un git reset --HEAD~1 para eliminar todos los cambios y deshacer el ultimo commit
#¿Cuándo preferirías descargar cambios sin fusionar (fetch) en lugar de
descargar y fusionar (pull)?
-Es preferible usar git fetch en lugar de git pull cuando necesitas revisar los cambios del repositorio remoto antes de integrarlos en tu código actual para evitar sorpresas o conflictos inesperados
#¿Por qué es peligroso usar el comando que fuerza el push (push --force)?
-Usar git push --force es peligroso porque sobrescribe de forma permanente el historial remoto en el servidor, lo que puede borrar el trabajo de otros compañeros y romper el proyecto.
